# DLsite 以外で買った作品もフォルダ名をそろえる 設計

2026-11-27

## 目的と理由

ユーザーは DLsite 以外でもゲームを買っているが、どこで買ったかは覚えていない。「フォルダ名をそろえる…」は今 RJ番号の作品しかそろえられないので、DLsite 以外の作品は検索しても見つからないか、似た名前の違う作品が候補に出る。これらも「お店 番号 正式な作品名 v版」にそろえたい。

手元を調べた結果（RJ番号がわからない 59 フォルダ）：`steam_appid.txt` に番号があるのは 1 作品だけ。`steam_api.dll` は 16 作品にあるが DLsite のゲームにもよく入っている。FANZA の番号は 0。**ファイルからお店を自動で決めるのは難しい**ので、ユーザーがお店のページを見つけて URL を貼る形にする。

## ねらい・やらないこと・失敗とみなすこと

ねらい
- 一覧の行を右クリックして、お店の作品ページの URL を貼ると、お店と番号を読み取り、正式な作品名を取って `Steam 1234560 正式な作品名 v1.02` / `FANZA d_123456 正式な作品名` にそろえる
- 対応するお店：Steam、FANZA（同人・PCゲーム）
- 対応していない URL・作品名が取れないときは、作品名（とお店の名前）を自分で入れられる
- 一度そろえたフォルダは、次から「ブックマークにない作品」に出さない（もう一度検索しない）

やらないこと
- どのお店で買ったかの自動判定（手がかりが少ないため）。ただし `steam_appid.txt` に番号があれば、候補として最初から入れておく
- DLsite 以外の作品の所持チェック・AS での更新の確認
- お店へのログインや購入履歴の読み込み

失敗とみなすこと（動いていても）
- 番号と作品名が別の作品のものになる（URL の読み違い）
- そろえたフォルダが次の「フォルダ名をそろえる…」でまた検索・候補に出る
- 番号以外（フォルダ名など）をお店に送る

## 決めたこと

### 貼る URL と読み取り
- Steam：`store.steampowered.com/app/<番号>` → `Steam <番号>`
- FANZA：URL の `cid=<番号>`（`/dc/doujin/`・`/digital/pcgame/` など）や `dlsoft.dmm.co.jp/detail/<番号>` → `FANZA <番号>`
- RJ番号を含む URL・文字は今までどおり RJ番号として扱う
- どれにも当たらなければ、「作品名を入れる」に切り替える

### 正式な作品名の取り方（送るのは番号だけ）
- Steam：`https://store.steampowered.com/api/appdetails?appids=<番号>&l=japanese` の `name`
- FANZA：作品ページの `og:title`（年齢確認の cookie `age_check_done=1` を付ける）。取れなければ作品名を入れてもらう
- 取った名前は今の RJ番号と同じく、画面を開き直すまで覚える

### 名前の形
- `<お店> <番号> <正式な作品名> v<版>`（版は今の名前から読めたときだけ、今と同じ）
- 自分で作品名を入れたとき：`<お店の名前> <作品名> v<版>`（お店の名前は空でもよい。空なら `<作品名> v<版>`）

### そろえたものを次から出さない
- `rename-logs` の記録で変えた後の名前（NewPath）になっているフォルダは、「ブックマークにない作品」から外す（お店の形でも、自分で入れた名前でも同じ）。「フォルダ名を戻す…」で戻したものは、また出る

### 画面
- 右クリックの「RJ番号を入れる…」を「RJ番号・お店の URL を入れる…」にする。入力は1つの欄で、RJ番号・URL のどちらでもよい
- 一覧の「決め手」は「お店の URL（Steam）」などと出す
- `steam_appid.txt` に番号がある作品は、RJ番号の欄の候補に `Steam <番号>` を入れておく（チェックは付けない）

## 案

| 案 | 中身 | 良いところ | 悪いところ |
|---|---|---|---|
| **1. お店のページの URL を貼る（採用）** | URL からお店と番号を読み、正式な名前を取る | 覚えていなくても、作品名で探したページを貼るだけ。正式な名前になる | 対応外のお店は自分で入れる |
| 2. 作品名を自分で入れる | お店と作品名を打つ | どのお店でも使える。ネット不要 | 調べて打つ手間。打ち間違いが残る |
| 3. 案1＋Steam の自動判定 | `steam_appid.txt` から最初から入れる | 手間が減る | 今は1作品だけ。案1に候補として入れるだけにした |

ユーザーは案1を選んだ。対応外の URL のときに案2の入力に切り替えるのは、提案に含めて選ばれた。

## 作る人に任せること
- FANZA の URL の形の網羅と、作品名が取れるかの確認（取れない形は「作品名を入れる」へ）
- 入力の画面の見た目（1つの欄＋必要なら作品名・お店の名前の欄）
- テスト：URL の読み取り、名前の組み立て、Steam/FANZA の返事の読み取り（保存した見本で）、そろえたフォルダを外す処理
